# 美顏相機

純網頁版美顏相機。影像處理全部在瀏覽器本機完成，拍攝的照片不會上傳到任何伺服器。

## 功能（v4）
- **美膚**：磨皮（只作用在膚色區域）、美白、紅潤、去黑眼圈
- **五官**（MediaPipe 人臉關鍵點，最多 2 張臉）：大眼、嘴型（放大／縮小）、亮眼、美牙
- **彩妝**：唇色、腮紅、立體（鼻樑、額頭、下巴尖的自然高光）
- **畫質**：亮度、對比、飽和、清晰、暗角
- **濾鏡**：原圖、日系、冷調、粉嫩、清透
- **美顏模式**：自然、甜美、清透、重置（一鍵套用整組參數，在「濾鏡」分頁）
- 九宮格輔助線（畫面右上角 ▦）
- 前後鏡頭切換、倒數計時（3／5／10 秒）
- 拍照後預覽、下載、分享

## 部署到 GitHub Pages
1. 在 GitHub 建立新儲存庫（例如 `beauty-camera`），設為 Public
2. 把 `index.html`、`style.css`、`app.js`、`README.md` 一起上傳到儲存庫根目錄
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save
4. 約一分鐘後，網址會是 `https://你的帳號.github.io/beauty-camera/`

> 相機功能需要 https，GitHub Pages 預設就是 https。
> 更新時請把所有檔案一起覆蓋，並在手機上強制重新整理，避免新舊檔案混用。

## 關於外部資源
人臉偵測的程式庫（jsDelivr）與模型檔（Google Storage）會在開啟網頁時從網路下載，約數 MB，之後瀏覽器會快取。
下載的只是模型，你的相機畫面與照片仍然只在本機處理。

## 調整建議（皆在 `app.js`）
- 大眼範圍／強度：`uploadFaceUniforms` 裡的 `* 0.8`、`big * 0.5`
- 嘴型範圍／強度：同一處的 `* 0.6`、`mouthS * 0.3`
- 腮紅、黑眼圈、高光的位置與大小：`drawBlobs` 裡的 `fw * …` 係數
- 腮紅顏色：shader 裡的 `vec3(.22,.05,.08)`
- 磨皮質感：shader 裡的 `90.0`（越小越平滑）與 `0.25`（找回的細節量）
- 美顏模式的參數：`PRESETS`
